## Scope and Measured Coverage

The 2026-09-30 audit measured module and screen presence. It did not establish
complete business logic, source API compatibility or physical meter operation.
The following measurements have different denominators and must not be added
or presented as one overall parity percentage.

routes. The three dedicated methods are not an overall functional API score.
There is no defensible overall functional parity percentage yet.

## Implemented Corrections

- Device simulation requires explicit `DEVICE_SIMULATION_ENABLED=true`.
  Production Compose sets it to false. Monitor, reading views and report
  calculations exclude SIM rows when simulation is disabled. Legacy `COLLECT`
  and `RECOLLECT` rows generated by the former demo adapter are also excluded;
  no historical data is deleted. Demo collection cannot overwrite genuine rows.
- Disconnected reading collection, relay switching/device refresh, device limit
  writes and telesignal commands return 501 before changing stored evidence.
- Database relay refreshes no longer advance device timestamps or mark a command
  completed. Local limit configuration remains available as `CONFIGURED`, with
  `DEVICE_CONFIRMED=false`.
- Operator mutations require `config` privilege. A reports-only viewer cannot
  issue commands or alter signal, meter or automation configuration.
- Unimplemented model/source-action routes no longer return misleading empty
  successes or execute a generic grid in place of their business operation.
- The daily profile viewer uses `measurementsarchives` and `archives/point`,
  including selected ML/MD/AGGS, UTC+08 calendar bounds, exact decimal values,
  original intervals, source read time and tariff provenance. Empty data stays
  empty. It no longer inserts five synthetic bars or labels A+ energy as P+ power.
  Filter selection is preserved when opening the profile; an unavailable selected
  series is never silently replaced by another measurement.
- GIS no longer assigns pixel-offset coordinates by array index, pairs meters
  by array position, or treats auto-read configuration as recent data. The
  authenticated reference API supplies the dated 2026-09-14 coordinate capture:
  39 valid coordinates, one malformed coordinate, 47 with no coordinate response.
  Reference coordinates are used only for unambiguous exact-name matches; current
  verified stored coordinates take precedence. The local seeded installation has
  18 such matches and 69 unlocated records. Missing geometry stays absent.
  This supersedes the earlier claim that 46 visually traced positions were
  source coordinates. Coordinate reference data is not embedded in public JS.
  `gis/availability` uses stored observation times and current meter mountings,
  excludes SIM when disabled and does not invent a read time for missing values.
- Report generation no longer manufactures missing energy/technical readings,
  assumes a fixed 2.5% loss or claims completeness from an unverified polling rate.
  Beginning/end readings follow timestamp order. Unverified consumption and
  balance calculations remain null.
- Channel configuration is not treated as period-by-period archive quality.
  Source-style quality colors remain unknown; the existing local interval
  coverage screen remains available at `/m/qualityreports`.
- `cmd/teamisync` provides an operational one-shot archive importer with explicit
  source/target IDs, unit, dates and verified IANA timezone. Secrets come from the
  process environment. Existing transactional storage preserves missing evidence,
  exact decimals and receipt IDs; replay is idempotent and corrections fail explicitly.
- Frontend `version.json` and backend `/health` expose their build commit.
  Deployment validates secrets before syncing, checks out the CI-tested commit,
  verifies both deployed commit IDs and verifies marker MIME type.
- Missing static assets return 404 instead of the SPA shell. The improvement
  branch now runs CI; automatic production deploy remains limited to main/master.
- CI exposed the transitive `source-map-js` 1.2.1 dependency advisory
  [CVE-2026-93749](https://github.com/7rulnik/source-map-js/releases/tag/v1.2.2).
  Only that lockfile entry was upgraded to patched 1.2.2; the security gate stays
  enabled. The subsequent npm audit reports zero known vulnerabilities.
- The offline preview build excludes production public assets; imported assets
  remain inlined. Added GIS PNG directories no longer break its strict single-file
  packaging. Production's public marker assets are unchanged.

## Verification

- Production/source authenticated navigation sweep: 11/11 per application.
- TypeScript check and frontend production build pass.
- Archive/coverage/geometry frontend tests: 16 pass; existing preview/GIS/window tests: 11 pass.
- Full Go suite: 78 test cases pass, zero failed/skipped tests; vet passes using Go 1.26.9.
- PostgreSQL 16.15 was run in a fresh workspace cluster bound to loopback, separate
  from production. Full API integration tests pass, including all 858 model
  read/grid requests. The additional 718 source method checks pass their expected
  success, validation or unsupported contracts.
- Additional GIS evidence test confirms that auto-read flags and SIM rows never
  produce recent-reading evidence, while a genuine stored zero does.
- Source HTTP fixture -> transactional storage -> authenticated archive API is
  tested, including decimal precision, zero, null receipt evidence, timezone,
  replay, rollback, source read time and tariff metadata.
- Local GIS renders the mapped geometry with source PNG pins at desktop and
  390x844; all 87 records remain and the 69 unlocated records are disclosed.
  Device collection/relay buttons are disabled without an adapter. Browser click
  delivery for relay row selection/DB refresh could not be verified; its backend
  non-mutation contract is covered by the integration suite.

Tests prove local contracts and explicit failure boundaries. They are not a
claim that 715 unsupported source methods have been implemented.

diagram layout and navigation remain. Unknown device evidence is kept unknown.
