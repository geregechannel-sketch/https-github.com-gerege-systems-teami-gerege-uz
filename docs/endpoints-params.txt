# TEAMI / EMCOS EC3 — Endpoint параметрийн бүтэц (982)
#
# Эх сурвалж: браузерын webpack model config-уудаас (route + request_label + structure)
#   бүх 852 chunk ачаалж олборлов (2026-08-28). Зам бүр ec3api/v1/ суурьтай харьцангуй.
#
# Формат:  <path> [METHODS] :: PARAM(flags), PARAM2(flags), ...
#   METHODS — request_label-аас (GET/POST/PUT/DELETE). "[-]" = label тодорхойгүй
#             (ерөнхийдөө GET унших / POST бичих; action-оор шийдэгдэнэ).
#   Туг (flags):
#     get=req  — GET query параметр, ЗААВАЛ
#     get=opt  — GET query параметр, сонголтоор
#     add=req  — POST/PUT body талбар, ЗААВАЛ
#     add=opt  — POST/PUT body талбар, сонголтоор
#     nonNull=req — null байж болохгүй (заавал утгатай)
#     query    — query string-д (POST үед)
#   Туггүй параметр = ихэвчлэн хариунд буцдаг/дотоод талбар (жишээ ID).
#   Нэг параметр олон туг агуулж болно (GET ба POST-д өөр өөр үүрэгтэй).
#
# ЖИШЭЭ бичих хүсэлт (POST):
#   POST ec3api/v1/points
#   header: st-token: <JWT>
#   body: { "POINT_NAME":"...", "POINT_CODE":"...", ... }  // add=* талбарууд
# ЖИШЭЭ унших (GET):
#   GET ec3api/v1/measuringdevices?offset=0&limit=100      // get=* параметрүүд
#
# Grid query (жагсаалт): POST <path> body { limit, offset, filters:[{c,p,v}], ... } -> { data, totalCount }
# ============================================================================
