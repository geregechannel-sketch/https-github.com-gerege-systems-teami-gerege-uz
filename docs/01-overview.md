# 01 — Системийн ерөнхий тойм

## 1.1 Зорилго
**TEAMI Enterprise** нь цахилгаан эрчим хүчний **арилжааны болон техникийн хэмжилтийн
өгөгдлийг** удирдах систем (MDM — Metering Data Management) юм. Тоолуур/контроллероос
өгөгдөл автоматаар цуглуулж, хадгалж, боловсруулж, баланс/тооцоо, чанарын хяналт,
тайлан, ачаалал удирдлагыг хангадаг. Энэ нь **EMCOS / EC3** (Sigma Telas) бүтээгдэхүүний
`3.0` хувилбар бөгөөд TEAMI Enterprise нэрээр брэндлэгдсэн.

Ажиглагдсан суурилуулалт: **TOSH ELECTROAPPARAT** брэнд, **Монгол** дахь deployment
(Монголия → г.Чойбалсан, ЖКН№8 → Дорнод-РЭС → ТП 43). Статистик: 87 тооцооны цэг,
30 унших цэг, 7 өгөгдөл цуглуулах сервер (DAS), холбооны сувгийн бэлэн байдал 100%.

## 1.2 Хамрах хүрээ (модулиуд)
Дээд түвшний 10 модуль (frontend dashboard):

1. **Сохраненные формы** — хэрэглэгчийн хадгалсан харагдац/формууд.
2. **Просмотр архивов** — хэмжилт/тооцооны цэгийн архив өгөгдөл харах (цаг хугацааны цуваа).
3. **Качество показаний** — архивын бүрэн бүтэн байдал ба өгөгдлийн чанарын шинжилгээ.
4. **Регистр событий** — систем/холбоо/өгөгдлийн үйл явдлын бүртгэл, аудит, холбооны статистик.
5. **Считывание показаний** — ИИК ба төхөөрөмжтэй бодит цагийн холбоо, унших.
6. **Конфигурация системы** — цэг/тоолуур/төхөөрөмж/бүлэг/толь бичиг тохируулах, хэрэглэгч удирдах.
7. **Отчеты** — тайлан үүсгэх, харах, автомат тайлан, тайлан засварлагч.
8. **Телесигналы** — телесигнализацийн тохиргоо, боловсруулалт.
9. **GIS** — объектуудыг газрын зураг дээр харах.
10. **Управление нагрузкой** — реле/лимит удирдах (ачааллын удирдлага, RGB/BGA төлөвлөлт).

> Дэлгэрэнгүй дэд модуль (137 маршрут) → [05-functional-spec.md](05-functional-spec.md).

## 1.3 Оролцогч талууд
- **Оператор / инженер** — өдөр тутмын хяналт, унших, архив/чанар шалгах.
- **Тохиргооны админ** — цэг/тоолуур/бүлэг/толь бичиг, хэрэглэгч/эрх.
- **Тайлан хэрэглэгч** — баланс, алдагдал, чанарын тайлан.
- **Системийн админ** — DAS, аудит, SQL debug, DB тохиргоо.

## 1.4 Гол чадвар
- Олон эх сурвалжаас (тоолуур, контроллер, DAS) өгөгдөл автомат цуглуулах.
- Цэг/бүлэг/хэмжилтийн иерархиар архив өгөгдөл хадгалах, харах.
- Баланс тооцох, алдагдлын wizard, эдийн засгийн профиль.
- Өгөгдлийн чанар/бүрэн бүтэн байдлын хяналт, орлуулга (substitution).
- Ачаалал удирдлага (power control plan/history, RGB/BGA offers).
- Тайлан (засварлагч, executor, автомат хуваарь), GIS.
- Аудит, үйл явдлын бүртгэл, олон хэл (7 хэл), theming.

## 1.5 Толь бичиг (нэр томьёо)
| Товчлол | Тайлбар |
|---------|---------|
| ТУ (точка учёта) | Тооцооны/хэмжилтийн цэг (POINT) |
| DP (data point) | Өгөгдлийн цэг/суваг (channel), `ST_DP` |
| DAS | Data Acquisition Server — өгөгдөл цуглуулах сервер |
| ИИК | Хэмжилтийн мэдээллийн систем (measuring info complex) |
| TFF | Tariff Form Factor — тарифын хэлбэр |
| WITHESET (databranchset) | Өгөгдлийн салбар/эх сурвалжийн багц |
| FFP | Favourite/Filter Profile — цэгийн мод дахь шүүлтүүр профиль |
| RGB / BGA | Ачаалал/үүсгэлтийн төлөвлөлтийн модулиуд |
| EMCOS / EC3 | Үндсэн бүтээгдэхүүн (Sigma Telas) |
