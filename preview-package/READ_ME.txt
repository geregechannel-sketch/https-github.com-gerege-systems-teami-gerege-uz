TOSH GIS — OpenStreetMap

1. ZIP дээр баруун товч → Extract All / Бүгдийг задлах.
2. Задалсан хавтаснаас START_MAP.cmd ажиллуулна.
3. Browser GIS хуудас нээнэ. Хар цонхыг нээлттэй байлгана.
4. Дуусгахдаа хар цонхонд Ctrl+C дарна.

Python 3 хэрэгтэй. Байхгүй бол эхлүүлэгч тодорхой мэдэгдэл харуулна.
OpenStreetMap суурь зурагт интернэт хэрэгтэй.
39 цэг нь TEAMI-ийн хадгалсан бодит координат. Заалт шууд шинэчлэгдэхгүй.
Таны төхөөрөмж дээр л дотоод вэб сервер ажиллана; TOSH production сервер өөрчлөгдөхгүй.
