GIS засвар — 2026-09-14

Хийсэн: томьёогоор зохиосон координатын цэгүүдийг арилгав; нийт тоолуурын тоог 48 цагийн заалтын тоо болгон харуулахыг болиулав; дугаар/ID хайлт, тоолуурын дэлгэрэнгүй сонголт, масштаб, жагсаалт хүлээн авсан цаг, алдааны мэдэгдэл нэмэв. Vite-ийн зургийн төрлийн тодорхойлолтыг нэмэв.

Шалгалт: npm ci, npm run build, tsc -p frontend/tsconfig.json амжилттай. Браузерийн харааны туршилт, бодит TEAMI холболт, production deployment хийгдээгүй.

Энэ нь эхний засвар. Бодит цэгийн координат болон сүүлийн заалтын огноо нийлүүлэх API холболт шаардлагатай. Тоолуурын жагсаалт эхний 1000 хүртэл мөртэй хэвээр; нийт тоо болон ачаалсан мөрийн тоог тусад нь харуулна. Эхлэл/буцах болон суурь зураг сонгох бүрэн GIS parity хараахан хийгдээгүй.

Шинэ GitHub repository Public хэвээр тул кодыг нийтлээгүй. Private болгосны дараа импортлоно. Эх ZIP-ийн бусад файлуудыг өөрчлөөгүй; үйлдвэрлэлийн deploy workflow энэ багцад анхны хэлбэрээр хадгалагдсан бөгөөд импорт нь production deploy гэсэн үг биш. Git-ийн өмнөх commit түүх ZIP-д байхгүй.
